Best Tank Mates for Convict Cichlids

Good tank mates for a convict cichlid include mystery snails, nerite snails. Small but extremely aggressive, especially when breeding, which it does readily.

Adult size4.7 in (12 cm)
Minimum tank30 gallons (114 L)
Temperature68–82 °F (20–28 °C)
pH6.5–8
TemperamentAggressive
Group sizeAlone or a pair
Swims atBottom
DietOmnivore
Care levelEasy
Scientific nameAmatitlania nigrofasciata
